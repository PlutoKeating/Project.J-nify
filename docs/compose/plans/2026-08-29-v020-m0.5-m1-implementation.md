## 一、目标与原则

本期交付（对应 I1/I2 定案）：
- **M0.5**：本地提醒闭环（Android 本地通知）、账户/隐私修正（忘记密码、彻底注销、隐私文案）、宣传口径标注、admin 面板 + Jennifer agent 基础 harness。
- **M1**：四信号源（usage/系统日历/天气/位置）+ 自然语言对话闭环 + 提醒节奏表 + 频控重构 + 离线队列 + 指标埋点。

核心原则（来自 DECISION_REGISTER §一）：
1. 执行层本地优先；不引入 Firebase/任何新推送服务。
2. Jennifer agent 接管策略决策；系统不硬编码上限/阈值/强制模板。
3. 原始信号本地；事项/决策上云匿名+加密；指标匿名。
4. 外部服务白名单：天地图 / OpenWeather / models.dev / GitHub API。
5. 无硬频控上限；保留安静时段 + 窗口级去重。

## 二、目标架构

```text
[ Flutter App（执行层 + 采集层） ]
   ├─ 信号采集（本地）：UsageStats / 系统日历 / OpenWeather / 定位+天地图
   ├─ 本地窗口引擎（Dart 规则移植）→ 窗口出现 → 本地通知（含"别再提"action）
   ├─ 离线队列（SQLite）：capture/decision/profile 离线暂存，重连自动同步
   ├─ 对话 UI ↔ POST /v1/jennifer/chat（Jennifer agent）
   ├─ 引导框架（feature-tour registry，本地）
   └─ 事项/决策/指标事件 → 后端（匿名指标；事项加密传输）
        │
[ Cloudflare Worker（决策层 + 数据层 + 管理面） ]
   ├─ REST /v1/*：items(CRUD)/now/decision/guardrails/me/profile/auth 数据
   ├─ POST /v1/jennifer/chat：agent harness（工具调用循环）
   ├─ POST /v1/metrics/events：匿名指标；SQL 视图算闭环率
   ├─ /admin（SPA）+ /admin/api/*：LLM 配置、系统配置、指标看板、告警配置
   ├─ 告警：GitHub Issues（GH_PAT）+ SMTP 邮件（双通道）
   └─ Supabase：数据表 + 迁移 + RLS（不变：客户端零直连）
        │
[ Website + README + 文档 ]
   ├─ 官网：状态标注 / /auth/verify 回退页 / 隐私政策页 / OpenWeather 署名
   └─ README/SPEC/release.md：三态徽章、验收用例、版本状态、GAP 登记
```

## 四、App 模块任务清单（app-agent）

### 4.1 依赖
- 新增（均为本地/设备能力，非外部服务）：`flutter_local_notifications`、`permission_handler`、`sqflite`、`shared_preferences`、`geolocator`、`http`（已有）。
- Android 原生平台通道：UsageStatsManager（`PACKAGE_USAGE_STATS` 引导页）、系统日历只读（CalendarContract）、可选无障碍服务（进阶开关）。

### 4.2 任务
1. **本地通知闭环（M0.5 核心）**：flutter_local_notifications 初始化；通知权限引导（E10：首启或首次录入成功后请求；拒绝后设置页可开启）；通知点击深链回「现在」页；通知内 action「别再提」→ 本地永久静默该事项（Q1）。
2. **本地信号采集（M1）**：
   - usage：UsageStatsManager 聚合（近 20 分钟连续使用阈值由 Jennifer 策略控制，本地默认 20min 仅作初始参考）；无障碍实时感知做成可选开关；检测结果仅本地。
   - 系统日历：只读未来 7 天空闲时段（≥15min 阈值参数化，默认值可被策略覆盖）。
   - 天气：OpenWeather（免费 key 配置项，坐标模糊化后请求；结果本地缓存）；"晴风"判定参数由策略下发。
   - 位置：geolocator 授权获取位置 → 坐标取整模糊化（约 1km）→ 天地图逆地理编码取城市/区域 → 本地使用；不上传坐标。
3. **本地窗口引擎**：把 `backend/src/services/window-engine.ts` 规则移植为 Dart（含 due_soon/weather/usage/manual + 节奏表 + 冷却，冷却值从策略读取）；`/v1/now` 仍可用但 App 以本地评估为准（GAP-DUAL-ENGINE 记录）。
4. **离线队列（E4 完整落地）**：SQLite 暂存 capture/decision/profile 更新；失败 Toast + 输入保留；重连自动同步（last-write-wins，GAP-OFFLINE-CLOUD 记录）。
5. **对话闭环（Q7/D2）**：新增对话入口（可挂在「现在」页顶部或新 Tab 逻辑）与消息流 UI；调 `POST /v1/jennifer/chat`；展示 agent 文本与工具执行结果（如"已创建事项 X"）；自然语言 CRUD。
6. **录入与焦点卡**：预计耗时选择（30s/5/15/30min → est_minutes）；三 chips（为什么是现在/约 X 分钟/可晚点）；空输入 Toast（E3）；失败重试（E4）。
7. **全部页**：每行显示窗口理由（E2，列表接口返回最新 reason_text）；按"进行中/已收口"分组、收口组默认折叠（C6）；"清空已收口"=软归档确认弹窗；长按进入多选 → 硬删（二次确认，逐条调 `DELETE /v1/items/:id`）。
8. **编辑**：事项长按/详情编辑标题/分类/期限/时长（调 `PATCH /v1/items/:id`）。
9. **设置与账户**：移除"反打扰上限"下拉（Q1）；忘记密码入口（D1）；注销账户（D3，二次确认 → `DELETE /v1/me/data` → 登出）；时区检测与切换弹窗（B9，写 `PUT /v1/me/timezone`）；隐私说明文案修正（D5）；通知权限开关入口（E10）。
10. **引导框架（E8）**：通用 feature-tour registry（本地 shared_preferences/sqlite：`{key, version, status: seen/completed/skipped}`）；onboarding_v1 首启；未来新功能沿用同一机制。
11. **品牌（E6）**：Android label → `J-nify`（strings.xml + manifest 引用）；iOS CFBundleDisplayName → `J-nify`；启动图标品牌化（#FF5A4E + 简单符号，生成 mipmap/AppIcon 全套）。
12. **体验（E5/E7）**：「现在/全部」下拉刷新 + 错误态重试按钮；问候语展示后端动态 greeting（E7）。
13. **指标埋点（G1）**：capture/nudge_sent(本地通知发送时)/nudge_opened(点击)/decision/rescue_action/complaint(别再提) → 匿名事件 POST `/v1/metrics/events`（仅 id/类目/状态/时长，不含内容）。
14. **测试与文档**：新增 widget/unit 测试（analyze 0 issues、测试全绿）；`frontend/docs/**` 同步更新。

### 4.3 不做（写 GAP）

## 五、后端模块任务清单（backend-agent）

### 5.1 admin 管理面板（F6/G2）
1. Worker 提供 `/admin` 单页应用（纯静态 HTML+JS 或极简打包，随 Worker 资产输出；同域，无新服务）。
2. `/admin/api/*`：登录（`ADMIN_USERNAME`/`ADMIN_PASSWORD`/`SESSION_SECRET` 环境变量，签名 session cookie，超时过期）、登出、会话校验。
3. **LLM 配置（热加载）**：多 provider（首批 OpenAI-compatible 类型：baseUrl + 多 key + 多模型；预留 anthropic 类型）、provider 增删改、key 轮换、模型列表（优先从 models.dev `https://models.dev/api.json` 动态拉取，下拉可选；也允许手填）、模型优先级列表（Jennifer 按序尝试，失败切换下一个）、启用/停用；配置存 Supabase `system_config` 表（JSON + version），Worker 内存缓存 + version 变更即失效，**保存后立即生效**。
4. **系统配置**：其他后台配置项（提醒策略默认值、告警阈值等）同机制。
5. **指标看板（G2）**：闭环率（SPEC §9.1：进入窗口后 72h 内完成/延期/放弃/兜底比例）、nudge 数、决策分布、投诉/关闭通知数；图表页。
6. **告警配置（G3）**：阈值设置 + 测试发送按钮（GitHub Issues / 邮件双通道）。

### 5.2 Jennifer agent harness（B6/B7/B8/C1/C2/C4/D2/F6）
1. `POST /v1/jennifer/chat`：输入用户消息 + 会话上下文 → 工具调用循环（LLM 多 provider 故障切换）→ 返回文本 + 工具执行结果。
2. **工具集（MCP 风格 JSON Schema 定义，自研 harness，不引入外部 MCP 运行时）**：
   - 事项：list/get/create/update/delete（含批量删除语义）；
   - 策略：读/写节奏表（rhythm）、冷却、安静时段、隐私授权、静默事项；
   - 话术/草稿：生成窗口理由、兜底草稿（延期申请/寄件清单/回复草稿）、问候语；
   - 护栏：读 guardrails；写用户偏好。
3. system prompt：品牌人设（Jennifer/懂 P 人的 J 人助理/不命令不羞辱/给理由给退路）、**参考话术列表（明确仅参考，非强制）**、工具使用规范、真实性红线（无信号不得编造理由）、涉及真实动作必须二次确认。
4. agent 不可用（无 LLM 配置/全 provider 失败）→ 诚实降级：返回可读错误 + 提示管理员配置，**不做硬编码兜底话术**（Q14）。

### 5.3 事项与账户 API
1. `PATCH /v1/items/:id`（标题/分类/期限/est_minutes）；`DELETE /v1/items/:id`（硬删）；列表接口返回最新窗口 reason_text（E2）。
2. `DELETE /v1/me/data` 增强：清业务数据后**调 Supabase admin API 删除 auth 用户**（彻底注销，Q17）；返回注销结果。
3. `PUT /v1/me/timezone`（B9）；`/v1/now` greeting 动态化（按用户时区的星期/时段，可选由 agent 生成，E7）；逾期文案修正（B10）。
4. `POST /v1/metrics/events`（匿名事件落库）+ 闭环率 SQL 视图（G1）。

### 5.4 窗口与频控重构（Q1/A3/B11/F1）
1. 移除 `max_nudge_budget` 硬门（保留字段供策略记录，不再作强制限制）；保留安静时段（按用户时区）+ 窗口级 nudge 去重（同 window_id 已有 nudge 则跳过）。
2. `/v1/now`：候选 limit 20 + `Promise.all` 并发窗口计算（带并发上限）；P95 基准脚本（`backend/scripts/bench-now.ts`）。
3. 节奏表落库（初始默认：账单 10/3、退货 3/5/1、作业 5/10/13、无死线同理由冷却 72h；Q15）→ agent 工具可读写。

### 5.5 告警（G3）
1. 评估逻辑：nudge 后投诉率、LLM 降级率、指标异常 → 触发。
2. GitHub Issues：`GH_PAT`（最小权限 fine-grained token，Issues read/write）→ `POST /repos/PlutoKeating/Project.J-nify/issues` 自动建单。
3. 邮件：`SMTP_HOST/PORT/USER/AUTH` → 直发 `j_nify@yeah.net` 告警邮件。
4. admin 面板可配阈值 + 测试发送。

### 5.6 测试、迁移与文档
1. 迁移：`system_config`、节奏表扩展、metrics 事件表、SQL 视图（均在 `backend/supabase/migrations/`，golden rule）。
2. 单元测试覆盖新逻辑（admin auth、LLM 配置校验、agent 工具、去重、时区、metrics）；`npm test` + typecheck 全绿；集成测试维持跳过（F3/Q12）。
3. 文档：`docs/API.md`（新端点）、`docs/ARCHITECTURE.md`（admin/agent/本地执行架构）、`docs/devops/SECRETS_REGISTRY.md`（§五新增 secret 指引）、HANDOVER 增量。

### 5.7 不做
- OAuth 日历源、FCM、生产库集成测试、导出。
