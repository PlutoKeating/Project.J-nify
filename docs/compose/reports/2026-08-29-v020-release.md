## 四、遗留（人工/条件性）

1. **真机冒烟（用户）**：侧载 `app-release.apk` → 注册/确认/登录 → 本地通知 +「别再提」action → 四信号实际采集 → 离线暂存重连 → 邮件深链回跳。
2. **管理员侧验证（用户）**：用新账密登录 admin → 告警「发送测试告警」→ LLM 对话端到端冒烟。
3. **账密双端同步（历史项，已解决）**：v0.2.0 验收当时 CF 与 GH 的 Admin 凭据一度不一致，因此当时不能从 GH 直接覆盖 CF。2026-08-30 管理员已更新 GH `ADMIN_USERNAME/ADMIN_PASSWORD`，重新同步 Worker 并通过只读生产冒烟。
4. **iOS**：未签名（需 Apple Developer 证书），已登记 GAP-IOS，本期排除。
